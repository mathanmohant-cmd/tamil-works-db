🔠 Pure Tamil Consonants (மெய் எழுத்துகள்)

Vallinam (வல்லினம் - Hard Consonants)

# Tamil English Type Example Notes
1 க் k Velar கல் (kal) Also: g → க
2 ச் ch, c Palatal செல்வம் (selvam) ch or c
3 ட் T Retroflex டமிழர் (Tamilar) Capital T
4 த் t Dental தமிழ் (thamizh) Small t
5 ப் p Labial பால் (paal) Also: b → ப
6 ற் R Alveolar அறம் (aRam) Capital R - unique!

💡 Quick Usage Tips

  • Case matters! Small = dental/short (t, n, e, o), Capital = retroflex/long (T, N, E, O, R, L)
  • Special combos: zh = ழ, ~N/N^ = ங, ~n/JN = ஞ, n2 = ன
  • Long vowels: Use double (aa, ii, uu) OR capitals (A, I, U, E, O)
  • Three N sounds: n (ந), N (ண), n2 (ன)
  • Examples: thirukkural → திருக்குறள், azhagu → அழகு, sa~Ngam → சங்கம், mathan2 → மதன்
