# Special Keys Guide for Tamil Transliteration

## 🎹 Where Are These Keys on Your Keyboard?

### Tilde (~) - For ங் and ஞ்

**Location:** Top-left corner of keyboard, same key as backtick (`)

**How to Type:**
- Press **Shift + `** (backtick key)
- On US keyboard: Left of number 1

**Usage:**
- `~N` → ங் (velar nasal, like "ng" in "sing")
- `~n` → ஞ் (palatal nasal, like "ny" in "canyon")

**Examples:**
```
sa~Ngam   → சங்கம்   (sangam/assembly)
~naanam   → ஞானம்    (knowledge)
~naayiRu  → ஞாயிறு   (Sunday/Sun)
```

---

### Caret (^) - Alternative for ங் and ஞ்

**Location:** Number row, above number 6

**How to Type:**
- Press **Shift + 6**

**Usage:**
- `N^` → ங் (velar nasal)
- (Note: There's no lowercase equivalent for ஞ using caret)

**Examples:**
```
saN^gam   → சங்கம்   (sangam)
```

---

### Number 2 - For ன்

**Location:** Number row, above letter Q

**How to Type:**
- Press **2** (no Shift needed)

**Usage:**
- `n2` → ன் (alveolar nasal)

**Examples:**
```
mathan2   → மதன்     (Cupid/love god)
en2       → என்      (my/me)
un2       → உன்      (your)
n2aan     → நான்     (I)
```

## 📝 Complete Reference Table

| Want This | Type Option 1 | Type Option 2 | Keys |
|-----------|---------------|---------------|------|
| ங் | `~N` | `N^` | (Shift+`) then N, OR N then (Shift+6) |
| ஞ் | `~n` | `JN` | (Shift+`) then n, OR J then N |
| ன் | `n2` | - | n then 2 |

## 💡 Pro Tips

### 1. **Tilde (~) is Easier**
- `~N` and `~n` are more intuitive than `N^` and `JN`
- Recommended for beginners

### 2. **Keyboard Layout**
```
┌───┬───┬───┬───┬───┬───┬───┐
│ ` │ 1 │ 2 │ 3 │ 4 │ 5 │ 6 │
│ ~ │ ! │ @ │ # │ $ │ % │ ^ │  ← Shift
└───┴───┴───┴───┴───┴───┴───┘
  ↑               ↑       ↑
  ~               2       ^
```

### 3. **Common Mistakes**

| ❌ Wrong | Why? | ✅ Correct |
|---------|------|-----------|
| na | Missing tilde | ~na |
| n~N | Wrong order | ~N |
| N~ | Missing second char | ~N + vowel |
| n_ | Underscore doesn't work | n2 |

### 4. **Remember:**
- **Tilde (~)** = Shift + backtick (`)
- **Caret (^)** = Shift + 6
- **Number 2** = Just press 2

## 🔤 All Three Nasal N Sounds

| Type | Tamil | Example | Keys |
|------|-------|---------|------|
| `n` | ந் | nalam → நலம் | Just n |
| `N` | ண் | kaN → கண் | Shift + n |
| `~N` | ங் | sa~Ngam → சங்கம் | (Shift+`) + (Shift+n) |
| `n2` | ன் | mathan2 → மதன் | n + 2 |
