## 💡 USAGE TIPS

### 1. **Case Sensitivity Matters!**

- **Small letters:** Dental (t, d, n), regular (r, l), short vowels (e, o)
- **Capital letters:** Retroflex (T, D, N, R, L), long vowels (E, O)

### 2. **Special Combinations**

- **zh** = ழ (NOT just "z")
- **~N** or **N^** = ங (velar nasal)
- **~n** or **JN** = ஞ (palatal nasal)
- **n2** = ன் (alveolar n)

### 3. **Common Mistakes**

| ❌ Wrong | ✅ Correct | Result |
|---------|-----------|---------|
| tamizh | thamizh | தமிழ் |
| aram | aRam | அறம் |
| vaNakam | vanakkam | வணக்கம் |
| azagu | azhagu | அழகு |
| mathan | mathan2 | மதன் |

### 4. **Vowel Usage**

Short vs Long vowels:
- **e** (short) → எ: erumai → எருமை
- **E** (capital, long) → ஏ: Ethu → ஏது
- **o** (short) → ஒ: oruvan → ஒருவன்
- **O** (capital, long) → ஓ: Om → ஓம்

### 5. **Double Consonants**

Use double letters for gemination:
- amma → அம்மா (mother)
- appa → அப்பா (father)
- kuRal → குறள் (couplet)
