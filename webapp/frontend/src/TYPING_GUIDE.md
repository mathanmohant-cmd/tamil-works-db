# Tamil Transliteration Typing Guide

## 🎯 Quick Reference: What to Actually Type

### Most Common Tamil Words (Simple Typing)

| Type This | Get This | Meaning |
|-----------|----------|---------|
| aram | அரம் | Virtue |
| thirukkural | திருக்குறள் | Thirukkural |
| thamizh | தமிழ் | Tamil |
| azhagu | அழகு | Beauty |
| sangam | சங்கம் | Sangam |
| naalaayira | நாலாயிர | Four thousand |
| kambaramayanam | கம்பராமாயணம் | Kamba Ramayana |
| vaLLuvar | வள்ளுவர் | Valluvar |
| mathan2 | மதன் | Cupid/love god |

### Special Letters (IMPORTANT!)

| Type | Result | Example | How to Type |
|------|--------|---------|-------------|
| **zh** | ழ | azhagu → அழகு | z + h |
| **~N** or **N^** | ங | sa~Ngam → சங்கம் | Shift+` then N, or N then Shift+6 |
| **~n** or **JN** | ஞ | ~naanam → ஞானம் | Shift+` then n, or J then N |
| **R** (capital) | ற | aRam → அறம் | Shift + r |
| **N** (capital) | ண | kaN → கண் | Shift + n |
| **T** (capital) | ட | Tamil → டமில் | Shift + t |
| **L** (capital) | ள | vaLLuvar → வள்ளுவர் | Shift + l |
| **n2** | ன | mathan2 → மதன் | n + 2 |

### Vowels (Two Systems)

#### Long Vowels (Two Ways)

| Type (Option 1) | Type (Option 2) | Result | Example |
|-----------------|-----------------|--------|---------|
| aa | A | ஆ | kaal → கால் |
| ii | I | ஈ | nIr → நீர் |
| uu | U | ஊ | Ur → ஊர் |

#### Short vs Long E and O

| Type | Result | Example |
|------|--------|---------|
| **e** (lowercase) | எ (short) | erumai → எருமை |
| **E** (uppercase) | ஏ (long) | Ethu → ஏது |
| **o** (lowercase) | ஒ (short) | oruvan → ஒருவன் |
| **O** (uppercase) | ஓ (long) | Om → ஓம் |

## 🔤 The Three "N" Sounds

Tamil has **three different "n" sounds**:

| Type | Tamil | Name | Example | Notes |
|------|-------|------|---------|-------|
| **n** | ந் | Dental n | nalam → நலம் | Default n |
| **N** (capital) | ண் | Retroflex n | kaN → கண் | Shift + n |
| **n2** | ன் | Alveolar n | mathan2 → மதன் | n + 2 |

### Examples with Alveolar n (n2)

```
Type: mathan2    → மதன்     (Cupid/god of love)
Type: en2        → என்      (my/me)
Type: un2        → உன்      (your)
Type: than2      → தன்      (self)
Type: man2       → மன்      (king)
Type: n2aan      → நான்     (I)
Type: en2n2a     → என்ன     (what)
```

## 💡 Pro Tips

### ✅ DO Use These:

1. **zh** for ழ (most important Tamil letter!)
2. **~N** or **N^** for ங (velar nasal)
3. **~n** or **JN** for ஞ (palatal nasal)
4. **Capital R** for ற (alveolar trill)
5. **Capital N** for ண (retroflex nasal)
6. **Capital L** for ள (retroflex lateral)
7. **Capital T** for ட (retroflex stop)
8. **n2** for ன (alveolar nasal)
9. **Capital E** for ஏ (long e)
10. **Capital O** for ஓ (long o)

### 🎯 Key Rules:

1. **Case Sensitivity Matters!**
   - Small: t, n, r, l, e, o (dental/regular/short)
   - Capital: T, N, R, L, E, O (retroflex/long)

2. **Special Combos:**
   - zh = ழ (NOT just z)
   - ~N or N^ = ங (velar nasal with tilde)
   - ~n or JN = ஞ (palatal nasal with tilde)
   - n2 = ன (alveolar nasal with 2)

3. **Double Letters for Gemination:**
   - amma → அம்மா
   - appa → அப்பா
   - vaLLuvar → வள்ளுவர்

4. **Vowel Length:**
   - Short: a, i, u, e, o
   - Long: aa/A, ii/I, uu/U, E, O

## ❓ FAQ

**Q: Why doesn't regular "n" work for மதன்?**
A: Tamil has 3 different "n" sounds. Use **n2** for the alveolar ன்.

**Q: What's the difference between e and E?**
A: **e** (lowercase) = எ (short e), **E** (uppercase) = ஏ (long e)

**Q: How do I type ழ?**
A: Type **zh** (z + h together)

**Q: Can I use just "z" instead of "zh"?**
A: No! You must type **zh** to get ழ

**Q: What about uppercase vs lowercase?**
A: Case matters! R ≠ r, N ≠ n, L ≠ l, T ≠ t, E ≠ e, O ≠ o
